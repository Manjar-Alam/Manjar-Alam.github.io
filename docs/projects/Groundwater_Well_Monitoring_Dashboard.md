## Overview

Developed an interactive India Groundwater Well Monitoring Dashboard to visualize and explore groundwater well information across different districts of Uttarakhand. The dashboard integrates spatial mapping, statistical indicators, charts, and tabular records to provide an overview of groundwater monitoring locations and well characteristics.

The application enables users to explore well distributions, distinguish between dug wells and bore wells, examine district-wise well counts, and view recorded groundwater-level information through an interactive dashboard interface.

**Study Area:** Uttarakhand, India

**Duration:** Personal GIS Project (2026)

**Role:** GIS Dashboard Development and Spatial Data Visualization

**Status:** Completed

## Methods & Tools

### Data & Spatial Components

- Groundwater well monitoring locations.
- District-wise well distribution.
- Dug well and bore well classification.
- Groundwater-level attributes.
- Administrative boundaries of Uttarakhand.

### Tools Used

- ArcGIS Dashboards
- ArcGIS Online
- ArcGIS Web Maps
- Esri Basemaps

---

## Key Features & Outcomes

- Developed an interactive spatial dashboard for groundwater well monitoring.
- Visualized groundwater well locations across Uttarakhand.
- Integrated district-wise well distribution charts.
- Displayed key indicators, including total wells, dug wells, bore wells, and average water level.
- Incorporated well-level attribute information in a tabular format.
- Enabled interactive exploration through state and well-type filters.
- Combined maps, charts, and statistical indicators for effective groundwater data visualization.

## Dashboard Components

| Component        | Description                                                      |
| ---------------- | ---------------------------------------------------------------- |
| Interactive Map  | Spatial distribution of groundwater wells                        |
| State Selector   | Filter records by state                                          |
| Well Type Filter | Explore different well categories                                |
| Indicator Cards  | Total wells, dug wells, bore wells, and average water level      |
| Bar Chart        | Number of wells by district                                      |
| Pie Chart        | Distribution of wells by type                                    |
| Attribute Table  | Site name, district, tehsil, village, well site, and water level |
