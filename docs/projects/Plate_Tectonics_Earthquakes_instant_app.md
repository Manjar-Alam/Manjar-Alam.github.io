## Overview

Developed an interactive earthquake visualization application using ArcGIS Instant Apps to explore the global distribution of seismic events and their relationship with tectonic plate boundaries and active fault systems. The application provides an interactive mapping environment for exploring recent earthquakes, analyzing their magnitude-based distribution, and understanding global seismic patterns in relation to tectonic settings.

The application integrates earthquake event data with tectonic boundaries, active faults, and plate information to provide an accessible geographic perspective on global seismic activity.

**Study Area:** Global

**Duration:** Personal Learning Project (2026)

**Role:** GIS Application Development and Spatial Visualization

**Status:** Completed

---

## Key Features & Outcomes

- Visualized the global distribution of recent earthquake events.
- Categorized earthquakes into magnitude-based classes for easy interpretation.
- Integrated earthquake locations with tectonic plate boundaries and active fault systems.
- Developed an interactive legend to explore different earthquake magnitude categories.
- Enabled geographic exploration of seismic activity across major tectonic regions.
- Demonstrated the application of Web GIS for communicating geophysical phenomena.
